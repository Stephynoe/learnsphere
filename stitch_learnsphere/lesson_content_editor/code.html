Prompt Templates and Output Parsers

PromptTemplates help create repeatable user prompts. We'll combine this with the PydanticOutputParser for deterministic JSON output straight from the foundation LLM.

chain_runner.py 
from langchain.prompts import PromptTemplate
from langchain_openai import ChatOpenAI

# 1. Instantiate the prompt schema
prompt = PromptTemplate(
    template="Summarize context in 3 bullets:\n{context}",
    input_variables=["context"]
)
chain = prompt | ChatOpenAI(temperature=0.0)
lightbulb
Pro Tip: Strict Schema Lock

Always configure temperature=0.0 when strict schema adherence is needed to minimize hallucinations in structured payloads.
